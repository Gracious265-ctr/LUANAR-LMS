# LUANAR-LMS Agent Instructions

## Project Context

Monorepo with a Next.js 16 (App Router, React 19, TypeScript, Tailwind v4) frontend in `frontend/` and a Django 6 + Django REST Framework (SimpleJWT auth, PostgreSQL, Supabase Storage, django-q2) backend in `backend/`.

Read `context/AGENTS.md` for application-building context, and `frontend/AGENTS.md` (auto-generated by `next dev`) for Next.js 16 changes before writing frontend code.

## Skill Auto-Loading Policy

Always load these skills at the start of any task in this repo, based on match — do not wait to be asked. If a task doesn't match a skill, skip it. Keep loaded skills minimal and context-efficient.

### Always load (core stack)
- `django-expert` — any Django/DRF/ORM/serializer/viewset/model/settings work in `backend/`
- `nextjs-developer` — any work on `frontend/` (App Router, server components, routes, middleware, metadata, next.config)
- `react-expert` — React/JSX components, hooks, component patterns, rendering issues
- `typescript-pro` — TS types, generics, type safety, API client modules in `frontend/lib`

### Load on task match
- `secure-code-guardian` — authentication, authorization, role checks, JWT tokens, input validation, OWASP concerns, CORS, Supabase credentials handling
- `test-master` — writing/running/analyzing tests (Django `manage.py test` in backend, Vitest + Testing Library in frontend) or test coverage
- `sql-pro` — slow queries, Django ORM query tuning, indexes, migrations, schema design
- `security-reviewer` — security audits, vulnerability review (e.g., secrets in committed files)
- `code-reviewer` — PR/code review, code quality audits, refactoring suggestions
- `fullstack-guardian` — tasks spanning both frontend and backend with a security focus (e.g., feature end-to-end with auth)

## Verification

- Backend: `uv run manage.py test` (from `backend/`, requires `CREATEDB` on the DB role)
- Frontend: `npm test` (from `frontend/`, Vitest run)
- Lint: run the project's lint scripts when relevant
